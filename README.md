# AI Chatbot

## Overview
An NLP-based chatbot built using Python and TensorFlow that classifies user intents from a custom dataset and generates contextual responses. The chatbot integrates WeatherAPI to provide real-time weather information based on user queries.

## Features
- NLP Intent Recognition
- Custom 500-Intent Dataset
- TensorFlow-Based Classification
- WeatherAPI Integration
- Real-Time Responses
- Unit Testing and Validation

## Tech Stack
- Python
- TensorFlow
- NLP
- WeatherAPI
- JSON

## Results
- Achieved ~92% training accuracy
- Trained on a custom 500-intent dataset
- Supports dynamic weather queries

## Future Improvements
- Voice Input Support
